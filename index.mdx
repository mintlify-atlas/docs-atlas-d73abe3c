La página de Seminarios y Eventos UIM es un sitio web estático desarrollado para la Facultad de Estudios Superiores Acatlán (UNAM) que permite a estudiantes, profesores e investigadores explorar el catálogo de seminarios de investigación activos, filtrarlos por categoría o búsqueda de texto, y enviar solicitudes de inscripción directamente desde el sitio.

## Primeros pasos

<Steps>
  <Step title="Descarga el repositorio">
    Clona o descarga el repositorio de GitHub y ábrelo en tu editor favorito.
  </Step>
  <Step title="Abre el archivo HTML">
    Abre `reestructuracion.html` en un navegador o sírvelo con cualquier servidor web estático.
  </Step>
  <Step title="Personaliza el catálogo">
    Edita el arreglo `seminarios` en `js/seminarios.js` para agregar, modificar o eliminar seminarios.
  </Step>
  <Step title="Ajusta los estilos">
    Modifica los archivos CSS en la carpeta `css/` para adaptar colores y tipografía a tus necesidades.
  </Step>
</Steps>

<Note>
  El sitio es completamente estático — no requiere servidor backend, base de datos ni dependencias de npm. Funciona con un servidor de archivos estáticos o directamente abriendo el HTML en el navegador.
</Note>
